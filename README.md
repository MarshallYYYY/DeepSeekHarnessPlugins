# turn-summary

[![开放插件市场](https://img.shields.io/endpoint?url=https%3A%2F%2Fdshopen.org%2Fbadge%2F%2540local%2Fturn-summary.json)](https://dshopen.org/zh/plugins/@local/turn-summary/)

将会话窗口右侧的轮次导航条UI进行修改：

1. 新增下方按钮（原始/大号），点击可切换到大号导航条显示，再次点击恢复原状
2. 新增上方摘要按钮，点击后可以显示用户每一次发出内容的前n个字符，用来快速查找到目标对话，也可以通过右键来编辑每一个对话内容的摘要。
